## Что делает мод

GOTC полностью заменяет набор ИИ-империй в галактике. Все ванильные прескриптованные
империи удаляются, вместо них в галактику попадают ~20 авторских империй-пародий на
реальные политические и культурные явления. Мод также переписывает стартовые системы,
угасшие империи, мародёров, анклавы, префтл-цивилизации и целый ряд связанных механик,
чтобы сгенерированная галактика выглядела как связная история, а не набор случайностей.

## Соглашения об именовании

Порядок загрузки файлов в Stellaris определяется алфавитной сортировкой имени файла
внутри каталога — более поздние файлы переопределяют более ранние. Мод активно этим
пользуется:

| Префикс | Смысл |
|---|---|
| `gotc_` | Собственный контент мода, не конфликтующий с ванилью |
| `zzz_` | Загружается последним — гарантированно переопределяет ванильный файл |
| `!!!_` | Загружается первым — используется для событий и инициализаторов |
| Ванильное имя | Файл-перезапись; нулевой размер означает удаление ванильного контента |

Все ключи локализации мода имеют префикс `GOTC_`.
